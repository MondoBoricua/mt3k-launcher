# ORBIT 0.1.4

ORBIT 0.1.4 is the first complete public ORBIT Plus release. ORBIT 0.1.3
introduced the entitlement foundation; 0.1.4 completes the product with real
Patreon, annual and lifetime access, the full premium feature set and a broad
update to the free launcher. ORBIT remains free, open source and fully useful
without Plus.

## New for everyone — ORBIT Free

- ORBIT stays navigable after a game starts. A stronger multi-signal tracker
  combines provider processes, process trees, install folders, package
  identity, executables, launcher hand-off and game-window evidence. It keeps
  playtime, manual-stop and automatic-return behavior explicit when Windows
  cannot verify a session.
- Played GeForce NOW titles participate in ORBIT's provider-neutral local Home
  history and can continue back into GeForce NOW. ORBIT Plus remains required
  for cloud-catalog matching and direct matched-game launches.
- The new controller-ready Download Center combines current and recently
  completed Steam, Epic and Xbox activity with progress, transfer speed, ETA,
  data-quality labels and the safest available pause/resume/stop or provider
  hand-off action.
- Game details now include a complete metadata workspace, a consolidated action
  menu, artwork resolution/quality guidance and safe YouTube search for
  replacement trailers and title music. Stable provider identities remain
  protected from manual edits.
- Steam sign-in, owned and Family library reconciliation, authenticated wishlist
  import and Store recommendations are more resilient without requiring a Web
  API key. An optional key remains available only as a fallback.
- Onboarding joins newly connected libraries to the running synchronization and
  no longer waits indefinitely for optional metadata or achievement providers.
- Retro support adds PlayStation 3 and Xbox 360 presentation, detection and
  emulator provisioning. Existing systems receive stronger folder and artwork
  matching.
- Native Steam Controller support joins the existing XInput, DualSense and
  DualSense Edge paths. Modal focus scopes, spatial navigation and the
  controller keyboard restore focus more predictably.
- The Power menu adds controller-ready sleep, restart and shutdown confirmation
  through a narrow native worker boundary.
- Russian joins English, German and Spanish across all launcher and native
  messages, including Cyrillic text entry and locale-aware formatting.

## ORBIT Plus — complete public launch

- A Patreon browser device flow verifies eligible memberships without exposing
  Patreon passwords, OAuth credentials or provider IDs to the renderer.
- Annual and lifetime license keys can be purchased through the official ORBIT
  routes and activated inside the launcher. Payment stays in the browser; the
  validated key is encrypted with Windows secure storage. Patreon, annual and
  lifetime access unlock the same provider-neutral Plus entitlement.
- License checks reject wrong products, invalid/test purchases, expired or
  disabled licenses and removed device activations. Annual access has a bounded
  offline window; lifetime access remains locally usable while still respecting
  authoritative revocation.
- The Next Game Picker is a controller-ready animated carousel that chooses
  from ready games and explains its pick using playtime, completion-time and
  rating signals.
- Achievement details gain controller browsing and an optional YouTube video
  solution selected through a main-process-gated search. Hidden achievements
  remain protected until their provider reveals them.
- Cuadro TV Launcher is an exclusive five-column Home layout with game-derived
  colour, centre-facing cover depth and an undistorted information drawer.
- GeForce NOW integration matches the local library against NVIDIA's regional
  catalog and launches through the browser or installed client. Native cloud
  game windows receive their own session, playtime, return and Home-history
  tracking; queue/login time is not counted as playtime.
- Plus also unlocks gentle and cinematic Home motion, six premium colour
  themes, independent corner styling, custom local launcher music and custom UI
  sounds.
- Plus members receive early beta access, feature polls and development updates.
  GeForce NOW accounts, games and NVIDIA subscriptions remain separate.

The Plus contract is enforced in the main process and documented in
[ORBIT Plus integration](../ORBIT_PLUS.md). Changing renderer state cannot
unlock privileged Plus operations.

## Installing and upgrading

Download only `ORBIT-XboxMode-Setup-0.1.4-x64.exe`. It contains the complete
desktop application, the Xbox Gaming Home AppX, ORBIT's public certificate and
the verified English installer. Run it from the Windows account that should own
ORBIT and approve the administrator prompt. Xbox Mode requires Windows 11 24H2
or newer and remains subject to Microsoft's market, policy and staged rollout.

ORBIT 0.1.3 uses the same Certum publisher and can update in place. The legacy
self-signed Beta 1 package remains intentionally retained during its one-time
publisher migration so Windows does not remove package-family-scoped data.
