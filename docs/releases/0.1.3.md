# ORBIT 0.1.3

ORBIT 0.1.3 is the first stable release with ORBIT Plus and the largest
controller, media and language update since 0.1.2. The free launcher remains a
complete local gaming home; Plus adds an optional, separately verified layer
for cloud gaming and premium personalization.

## ORBIT Plus

- Patreon is the first access route for the provider-neutral ORBIT Plus
  entitlement. A browser-based device flow keeps Patreon passwords, OAuth
  credentials and provider IDs out of the renderer.
- Sessions and cached entitlements are encrypted with Windows secure storage,
  expire locally at the server-provided deadline and support a bounded offline
  grace period. Disconnect locks features immediately, even if remote
  revocation is temporarily unavailable.
- GeForce NOW games can be matched against the local library, browsed in a
  dedicated cloud source and launched through the installed client or browser.
  A GeForce NOW account, compatible games and any NVIDIA subscription remain
  separate requirements.
- Plus also unlocks gentle or cinematic Home backdrop motion, six additional
  colour themes, independent corner styling and custom local launcher music and
  interface sounds.
- Locked features remain discoverable and lead to the controller-friendly Plus
  page. The main process enforces every privileged operation; changing renderer
  state alone cannot unlock them.

The public verification service was checked before release: it created a
short-lived device session, returned only the official Patreon authorization
host and required the device-bound verifier before polling. See
[ORBIT Plus integration](../ORBIT_PLUS.md) for the full contract.

## Games, media and metadata

- Game details can show safe provider-backed trailers and optional title music,
  with cancellation, cleanup, matching and URL boundaries designed for partial
  or unavailable metadata.
- A full metadata editor can override titles, descriptions, artwork/media URLs,
  genres, platforms, release information, completion times, requirements and
  other facts without changing a game's stable provider identity.
- Running-game indicators, improved launch detection and elevation-aware
  process tracking make launch and return behavior clearer.
- The primary game-card action can be set to launch immediately or open details.
- Launcher ambience and per-title music use independent volume, delay, fade and
  enable controls. User-selected audio is validated before it is stored.

## Xbox, social and library

- Optional Microsoft public-client sign-in enables Xbox friends and Xbox
  achievement access without shipping a client secret. Refresh tokens stay
  encrypted with Windows secure storage; access and Xbox/XSTS tokens remain in
  the main process.
- Local Xbox and Microsoft Store discovery now records Game Pass membership
  history and highlights newly detected membership games.
- Xbox identity reconciliation, package activity, installation metadata and
  title matching have been strengthened without making account sign-in a
  requirement for the local library.
- Background library refreshes preserve provider data during partial failures
  and avoid replacing newer state with stale asynchronous results.

## Controller, display and language

- The complete launcher and its native messages are available in English,
  German and Spanish. Language changes persist, roll back on save failure and
  apply without leaving mixed-language views.
- Text can be scaled from 75% to 150%. Layout, focus and controller navigation
  were exercised at 1280×720 and 1920×1080 in standard and compact density.
- Controller cursor mode supports mouse-oriented web content while restoring
  the real pointer cleanly. Spatial navigation, game-card activation and the
  on-screen keyboard received additional focus and back-navigation coverage.
- The background controller mode now lives in ORBIT's tray lifecycle, handles
  Windows startup and Xbox Mode launch paths, and suspends native hooks safely
  around updates.

## Reliability and updates

- AppX update downloads validate every GitHub redirect, use bounded retries,
  resume partial files and pause when a game or launcher download needs the
  connection. Every completed installer still requires the pinned Certum signer
  and GitHub SHA-256 digest.
- Launcher/provider parsing, game activity detection, external window
  activation and foreground return behavior have broader failure handling.
- The source tree includes an isolated ORBIT HUD Game Bar prototype under
  `experiments/orbit-hud`. It is not connected to the launcher and is not
  packaged in this release.

## Installing and upgrading

Download only `ORBIT-XboxMode-Setup-0.1.3-x64.exe`. It contains the complete
desktop application, the Xbox Gaming Home AppX, ORBIT's public certificate and
the verified English installer. Run it from the Windows account that should own
ORBIT and approve the administrator prompt. Xbox Mode requires Windows 11 24H2
or newer and remains subject to Microsoft's market, device-policy and staged
availability.

ORBIT 0.1.2 already uses the same Certum publisher and can update in place. The
one-time self-signed Beta 1 migration rules remain unchanged: the legacy package
is retained so Windows does not delete package-family-scoped data.
