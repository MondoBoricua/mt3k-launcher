# ORBIT 0.1.3 Stable Release Plan

Status: **release candidate validated; Certum signing and GitHub publication pending**

## Target

- Product version: `0.1.3`
- Windows and AppX version: `0.1.3.0`
- Release sequence: `13`
- Channel: `stable`
- Git tag: `v0.1.3`
- Public binary: `ORBIT-XboxMode-Setup-0.1.3-x64.exe`
- Distribution: one all-in-one EXE; GitHub's automatic source archives remain
  available

The public file contains the complete ORBIT application, Xbox Gaming Home AppX,
public certificate and English installation flow. The standard NSIS installer,
standalone AppX and ZIP remain local verification artifacts and must not be
uploaded as additional public binaries.

## Stable scope

The release introduces ORBIT Plus with Patreon-backed entitlement verification,
GeForce NOW integration, premium motion/appearance and custom audio. It also
ships English/German/Spanish language support, 75–150% text scaling, game
trailers and title music, metadata editing, Xbox friends/achievements and Game
Pass history, controller cursor mode, stronger background operation and a
resilient resumable updater. The isolated Game Bar HUD experiment is committed
as source only and excluded from packaging.

## Required gate

1. Confirm version agreement across package, lockfile, builder, release manifest
   and Xbox manifest.
2. Run `git diff --check`, both TypeScript projects and the production build.
3. Run every non-destructive `verify:*` target plus the relevant language,
   cloud/Plus and native background live checks.
4. Confirm the public ORBIT Plus service creates a device-bound session and
   returns the official Patreon authorization host.
5. Build the standard installer and Xbox all-in-one package with the pinned
   Certum certificate.
6. Run `verify:win`, `verify:xbox` and an independent extraction/hash comparison
   of the all-in-one payload.
7. Pass ORBIT Guardian with no unresolved blocker.
8. Commit all release inputs, merge through GitHub, tag the exact main commit,
   create a draft release and upload only the all-in-one EXE.
9. Download the draft asset again and re-check size, SHA-256, signer and RFC3161
   timestamp before publishing it as Latest.
