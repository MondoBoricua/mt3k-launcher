# ORBIT 0.1.4 Stable Release Plan

Status: **approved for publication on 2026-09-10**

## Target

- Product version: `0.1.4`
- Windows and AppX version: `0.1.4.0`
- Release sequence: `14`
- Channel: `stable`
- Git tag: `v0.1.4`
- Public binary: `ORBIT-XboxMode-Setup-0.1.4-x64.exe`
- Distribution: one signed all-in-one EXE; GitHub's automatic source archives
  remain available

The public file contains the complete ORBIT application, Xbox Gaming Home AppX,
public certificate and English installation flow. The standard NSIS installer,
standalone AppX and ZIP remain local verification artifacts and must not be
uploaded as additional public binaries.

## Stable scope

This is the first complete public ORBIT Plus release. It adds live Patreon,
annual and lifetime entitlement routes; Next Game Picker; achievement video
guides; the exclusive Cuadro Home layout; premium appearance/audio; and full
GeForce NOW launching, native session and Home-history integration. The free
launcher adds Russian, the Download Center, stronger game tracking and return,
the expanded metadata/media workspace, Steam wishlist and Family-library
improvements, Steam Controller support, PS3/Xbox 360 retro support and native
power controls.

## Required gate

1. Confirm version agreement across package, lockfile, builder, release manifest
   and Xbox manifest.
2. Run `git diff --check`, language parity, both TypeScript projects and the
   production build.
3. Run every non-destructive `verify:*` target plus the language, download,
   Plus, Cuadro, cloud-session, controller, settings and retro live checks.
4. Confirm the public ORBIT Plus service creates a device-bound Patreon session
   and that public annual/lifetime checkout routes resolve without embedding a
   secret.
5. Build the standard installer and Xbox all-in-one package with the pinned
   Certum certificate.
6. Run `verify:win`, `verify:xbox` and an independent extraction/hash comparison
   of the all-in-one payload.
7. Pass ORBIT Guardian with no unresolved blocker.
8. Commit all release inputs, merge through GitHub, tag the exact main commit,
   create a draft release and upload only the all-in-one EXE.
9. Download the draft asset again and re-check size, SHA-256, signer and RFC3161
   timestamp before publishing it as Latest.
